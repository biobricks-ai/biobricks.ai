ACTION_TYPE
Table storing the distinct list of action types used in the drug_mechanism table, together with a higher-level parent action type.
	DESCRIPTION:Description of how the action type is used
	PARENT_TYPE:Higher-level grouping of action types e.g., positive vs negative action

                                                                                                                       description         parent_type
0  Positively effects the normal functioning of the protein e.g., activation of an enzyme or cleaving a clotting protein precursor  POSITIVE MODULATOR
1                                           Binds to and activates a receptor, often mimicking the effect of the endogenous ligand  POSITIVE MODULATOR
2                Binds to a receptor at an allosteric site and prevents activation by a positive allosteric modulator at that site  NEGATIVE MODULATOR
3                                 Binds to a receptor and prevents activation by an agonist through competing for the binding site  NEGATIVE MODULATOR
4                           Prevents translation of a complementary mRNA sequence through binding and targeting it for degradation  NEGATIVE MODULATOR

ACTIVITIES
Activity 'values' or 'end points'  that are the results of an assay recorded in a scientific document. Each activity is described by a row.
	MOLREGNO:Foreign key to compounds table (for quick lookup of compound structure - can also link to compounds through compound_records table)
	ACTIVITY_COMMENT:Previously used to report non-numeric activities i.e. 'Slighty active', 'Not determined'. STANDARD_TEXT_VALUE will be used for this in future, and this will be just for additional comments.
	DATA_VALIDITY_COMMENT:Comment reflecting whether the values for this activity measurement are likely to be correct - one of 'Manually validated' (checked original paper and value is correct), 'Potential author error' (value looks incorrect but is as reported in the original paper), 'Outside typical range' (value seems too high/low to be correct e.g., negative IC50 value), 'Non standard unit type' (units look incorrect for this activity type).
	VALUE:Datapoint value as it appears in the original dataset.
	TEXT_VALUE:Non-numeric value for measurement as in original dataset
	STANDARD_TEXT_VALUE:Standardized version of non-numeric measurement

ACTIVITY_PROPERTIES
Table storing parameters and properties of Activity_IDs in the ACTIVITIES table - can be either independent variables that do not apply to the whole assay (e.g., compounds 'DOSE'), or dependent variables/results that are important in interpreting the activity values (e.g., 'HILL_SLOPE')
	TYPE:The parameter or property type
	RELATION:Symbol constraining the value (e.g. >, <, =)
	VALUE:Numberical value for the parameter or property
	UNITS:Units of measurement
	TEXT_VALUE:Non-numerical value of the parameter or property

              type relation  value units          text_value

2           TISSUE     None    NaN  None               Blood
3            ROUTE     None    NaN  None              Gavage

ACTIVITY_STDS_LOOKUP
Table storing details of standardised activity types and units, with permitted value ranges. Used to determine the correct standard_type and standard_units for a range of published types/units.
	STD_ACT_ID:Primary key.
	STANDARD_TYPE:The standard_type that other published_types in the activities table have been converted to.
	DEFINITION:A description/definition of the standard_type.

   std_act_id standard_type                                        definition
0           1          CC50       Concentration required for 50% cytotoxicity
1           2          EC50          Effective concentration for 50% activity
2           3          GI50  Concentration required for 50% growth inhibition
3           4          IC50         Concentration required for 50% inhibition
4           5            Ki                               Inhibition constant
